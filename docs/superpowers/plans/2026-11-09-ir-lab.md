# IR Lab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A four-VM Wazuh incident-response lab on one PC, driven by `./lab`: build, attack, confirm the alert, reset.

**Architecture:** Ansible on the host creates libvirt networks and VMs on linux F and configures them over a firewall-bypassing management network. A stdlib-only `lab` CLI wraps Ansible, `virsh` and attack modules. Attacks cross pfSense from the host, or run over management SSH for post-compromise scenarios.

**Tech Stack:** libvirt/KVM (`virsh`, `virt-install`), Ansible (ansible-core only), Python 3 + pytest + paramiko, Debian cloud images, pfSense CE, Wazuh 4.x all-in-one.

**Spec:** `docs/superpowers/specs/2026-11-09-ir-lab-design.md`

## Global Constraints

- Never modify existing VMs (`pfsense`, `debian13`, `win11`, `win2k22`), networks (`default`, `network`, `vlan-*`) or pools (`DCO1`, `default`, `Downloads`).
- Every libvirt object is prefixed `irlab-`, except the pool, which is exactly `irlab`.
- All lab files live in `<F>/ir-lab/`. Never touch anything else on F. `<F>` comes from `findmnt` for UUID `aae55af8-a3c4-4fad-ac70-4dfa00506615`, and its path contains a space, so use argv lists or Ansible `quote`, never unquoted shell.
- Networks: `irlab-wan` 10.19.0.0/24 (NAT, host .1, pfSense .2, static route 10.20.0.0/24 via 10.19.0.2); `irlab-lan` 10.20.0.0/24 (no host address, pfSense .1); `irlab-mgmt` 10.21.0.0/24 (host .254, no forward, `<port isolated='yes'/>`, pfSense .1).
- Hosts on both LAN and mgmt: web01 `.10`, office01 `.20`, wazuh `.30`.
- RAM: pfSense 1024 MB, web01 768, office01 512, wazuh 4096. All VMs boot BIOS.
- Virtual disks: wazuh 20 GB, pfSense 8, web01 6, office01 6.
- `lab` is one stdlib-only file at the repo root. `attacks/` and tests may use the venv.
- No sudo inside `./lab`, and no reboot handling. No fstab. Secrets go in gitignored `.lab/`. The only password in the repo is office01's weak one.
- Commits are local. Never push or create a remote. End every commit message with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. F is not mounted, or the ACL is gone after a reboot: `./lab up` prints the exact mount and ACL commands and exits 1, with no traceback (Task 1).
2. `./lab check` with no recorded attack, or after a reset: says so and exits 2, and never passes on old alerts (Task 1).
3. `./lab reset` when any VM lacks a `clean` snapshot: fails before stopping anything (Task 6).
4. `./lab attack` when the target is down or the trainee has already blocked the attacker: a one-line timeout message and exit 1, not a hang (Task 7).
5. `./lab destroy`: anything without the `irlab` prefix is never selected, and anything but the typed word `destroy` removes nothing (Task 6).
